Raster Creation

Raster Data Management

Descrição

Ferramentas para gerar novos conjuntos de dados raster (grades de células) a partir do zero ou com base em parâmetros definidos pelo usuário, em vez de converter dados existentes (como vetores ou TINs) ou importar imagens. Permite criar rasters com valores constantes, aleatórios ou baseados em funções simples para uso em modelagem, análise ou como máscaras.

Funções Principais / Ferramentas

  • Create Constant Raster: Gera um raster onde todas as células dentro de uma extensão especificada possuem um único valor constante definido pelo usuário.
  • Create Random Raster: Gera um raster onde cada célula recebe um valor aleatório, geralmente dentro de um intervalo especificado (ex: números inteiros entre 0 e 100, ou números decimais entre 0.0 e 1.0).
  • Create Normal Raster: Similar ao Random Raster, mas os valores aleatórios seguem uma distribuição normal (gaussiana) com média e desvio padrão definidos.
  • Parâmetros Comuns de Criação:
    • Output Extent: Define a área geográfica que o novo raster cobrirá (pode ser definida por coordenadas, por outra camada ou pela exibição atual).
    • Cell Size: Especifica o tamanho (resolução) de cada célula no raster de saída.
    • Data Type: Define o tipo de dado a ser armazenado em cada célula (ex: inteiro de 8 bits, ponto flutuante de 32 bits).
    • Number of Bands: Para rasters multibandas, define o número de bandas.
  • Uso como Máscara ou Base: Rasters criados podem ser usados como máscaras em análises (ex: um raster constante com valor 1 dentro da área de estudo e NoData fora) ou como base para cálculos em Map Algebra (MA).

Exemplos Comuns

Criar um raster com valor 0 para representar áreas fora de uma bacia hidrográfica, para usar como máscara em cálculos hidrológicos. Gerar um raster com valores aleatórios para simular a distribuição inicial de uma espécie em um modelo ecológico. Criar um raster constante com o valor médio de precipitação anual para uma região, para usar em um modelo de erosão simplificado. Gerar um raster base com valor NoData para preencher posteriormente com resultados de interpolação. Criar um raster para testes de algoritmos de processamento de imagem.
