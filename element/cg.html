Calculate Geometry Attributes

Tables

Descrição

Calcula e popula campos na tabela de atributos com valores derivados das características geométricas das próprias feições (pontos, linhas ou polígonos). Permite armazenar medidas como área, perímetro, comprimento, coordenadas do centroide ou coordenadas X/Y diretamente na tabela para fácil acesso, consulta ou uso em outras análises e rotulagem.

Funções Principais / Ferramentas

  • Seleção da Propriedade Geométrica: O usuário escolhe qual propriedade deseja calcular:
    • Para Polígonos: Área, Perímetro, Coordenada X do Centroide, Coordenada Y do Centroide.
    • Para Linhas: Comprimento (Length), Coordenada X do Ponto Inicial/Final/Médio, Coordenada Y do Ponto Inicial/Final/Médio.
    • Para Pontos: Coordenada X, Coordenada Y, Coordenada Z (se disponível).
  • Seleção do Campo de Destino: Especifica em qual campo (coluna) da tabela de atributos o valor calculado será armazenado. O campo deve ter um tipo de dado compatível (geralmente numérico - double/float).
  • Unidades de Medida: Permite escolher as unidades para o cálculo (ex: metros quadrados, hectares, quilômetros quadrados para área; metros, quilômetros, milhas para comprimento/perímetro). É importante que as unidades sejam consistentes com o sistema de coordenadas da camada.
  • Sistema de Coordenadas para Cálculo: Permite especificar se o cálculo deve ser feito usando o sistema de coordenadas da camada ou outro sistema (útil para obter áreas geodésicas, por exemplo).

Exemplos Comuns

Calcular a área em hectares de cada lote em uma camada de parcelas e armazenar em um campo 'Area_ha'. Calcular o comprimento em quilômetros de cada segmento de rio e salvar em um campo 'Extensao_km'. Adicionar as coordenadas geográficas (latitude e longitude) de cada cidade em campos 'LAT' e 'LON' de uma camada de pontos de cidades. Calcular as coordenadas X e Y do centroide de cada município para usar na rotulagem do mapa.

Nota: Esta ferramenta é frequentemente acessada através da interface da tabela de atributos (clicando com o botão direito no cabeçalho do campo) ou como uma ferramenta de geoprocessamento separada (ex: Add Geometry Attributes em ArcGIS Pro).
