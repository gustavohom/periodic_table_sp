RG

Generalization (Raster)

Raster Data Management

Descrição

Conjunto de operações que modificam os valores das células em um raster para simplificar, suavizar ou limpar os dados, geralmente removendo pequenas regiões isoladas ou preenchendo pequenas lacunas. É frequentemente usado para pós-processar resultados de classificação de imagens ou outras análises raster, melhorando a homogeneidade das regiões ou eliminando "ruído".

Funções Principais / Ferramentas

  • Majority Filter (Filtro de Maioria): Substitui o valor de cada célula pelo valor que ocorre com mais frequência em sua vizinhança definida (ex: 3x3 células). Suaviza regiões e remove células isoladas.
  • Nibble: Substitui células de uma máscara raster (geralmente representando áreas a serem preenchidas, como NoData ou classes específicas) pelos valores das células vizinhas mais próximas no raster de dados original. Usado para preencher lacunas ou remover pequenas feições.
  • Shrink (Encolher): Remove células das bordas externas de zonas (regiões de células com o mesmo valor), efetivamente encolhendo as zonas.
  • Expand (Expandir): Adiciona células às bordas externas das zonas, expandindo-as para dentro de zonas vizinhas (ou NoData).
  • Boundary Clean (Limpeza de Fronteira): Suaviza as fronteiras entre zonas, expandindo e encolhendindo alternadamente para eliminar fronteiras irregulares.
  • Region Group (Agrupamento por Região): Atribui um identificador único a cada região conectada de células que possuem o mesmo valor. Útil para analisar ou selecionar regiões individuais após uma classificação ou outra operação.
  • Thin (Afinamento): Reduz feições lineares representadas em um raster (com valor 1, por exemplo) para uma única célula de largura, preservando a conectividade. Usado em análise de redes a partir de rasters ou reconhecimento de padrões.

Exemplos Comuns

Limpar um mapa de uso do solo classificado removendo pequenos pixels isolados de uma classe dentro de uma região maior de outra classe (Majority Filter). Preencher pequenas áreas de sombra (classificadas como NoData) em uma imagem classificada usando os valores das classes vizinhas (Nibble). Remover pequenas ilhas de vegetação classificadas dentro de um corpo d'água (Shrink ou Nibble). Conectar pequenas lacunas em uma rede de estradas representada em um raster (Expand seguido de Shrink, ou Boundary Clean). Contar e analisar o tamanho de fragmentos florestais individuais após usar Region Group em um mapa de cobertura florestal.
