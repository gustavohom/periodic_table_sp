PJ

Projections & Transformations

Data Management (Vector)

Descrição

Gerencia os Sistemas de Referência de Coordenadas (SRC ou CRS) associados a camadas geoespaciais. Isso inclui definir o SRC correto para uma camada que não o possui ou transformar (reprojetar) uma camada de um SRC para outro. É fundamental para garantir que as camadas se alinhem corretamente no espaço e que medições (área, distância) sejam precisas.

Funções Principais / Ferramentas

  • Define Projection (Definir Projeção): Atribui ou sobrescreve a informação do SRC armazenada com uma camada. Esta ferramenta NÃO altera as coordenadas dos dados, apenas a sua interpretação. Deve ser usada apenas quando o SRC está ausente ou incorreto.
  • Project (Projetar): Transforma as coordenadas das feições de uma camada de um SRC de origem para um SRC de destino. Cria uma nova camada com as coordenadas recalculadas. Esta é a ferramenta correta para mudar o sistema de coordenadas de uma camada (ex: de Lat/Long para UTM). Requer que a camada de entrada já tenha um SRC corretamente definido.
  • Transformação Geográfica / Datum Transformation: Parte essencial da ferramenta `Project` quando os SRCs de origem e destino usam Datums geodésicos diferentes (ex: WGS84 para SAD69). É necessário escolher um método de transformação adequado para a região para garantir a precisão da conversão entre datums.
  • Identify Projection / Layer Properties: Ferramentas ou painéis para visualizar o SRC atual de uma camada.

Exemplos Comuns

Receber um Shapefile sem arquivo .prj e usar Define Projection para informar que seus dados estão em WGS84 (Lat/Long). Converter uma camada de pontos coletados em GPS (WGS84 Lat/Long) para UTM Zona 23S para realizar medições de distância em metros (Project). Alinhar uma camada em SAD69 com outra em SIRGAS 2000, utilizando uma transformação de datum apropriada durante a reprojeção (Project com transformação). Definir o SRC de um arquivo CAD importado que não tinha informações geográficas associadas (Define Projection após georreferenciamento/ajuste espacial, se necessário).

Atenção: Usar Define Projection quando se deveria usar Project (ou vice-versa) é um erro comum que leva a dados desalinhados.
