Image Stretching / Contrast Enhancement

Remote Sensing

Descrição

Técnicas aplicadas para melhorar a visualização de imagens raster (especialmente imagens de sensoriamento remoto), ajustando como os valores originais dos pixels (níveis de cinza ou brilho) são mapeados para a escala de exibição do monitor (geralmente 0-255). O objetivo é aumentar o contraste visual e realçar detalhes que podem estar ocultos na imagem original devido a uma faixa dinâmica limitada ou distribuição desigual dos valores.

Geralmente, esses ajustes afetam apenas a *exibição* da imagem, não os valores dos pixels armazenados no arquivo, a menos que a imagem seja exportada com o stretch aplicado.

Funções Principais / Técnicas Comuns

  • Histogram Stretch (Estiramento de Histograma): Mapeia um intervalo dos valores de pixel originais para toda a faixa de exibição (0-255).
    • Minimum-Maximum: Usa os valores mínimo e máximo reais da imagem (ou de um subconjunto) como limites para o estiramento.
    • Percent Clip: Descarta uma pequena porcentagem dos valores mais baixos e mais altos antes de aplicar o estiramento Mínimo-Máximo, útil para remover o efeito de outliers.
    • Standard Deviation: Define os limites do estiramento com base na média e em um número de desvios padrão (ex: 2 desvios padrão).
  • Histogram Equalization (Equalização de Histograma): Redistribui os valores dos pixels para que haja aproximadamente o mesmo número de pixels em cada nível de cinza na faixa de exibição. Aumenta o contraste global, especialmente em imagens com histogramas concentrados.
  • Gaussian Stretch: Aplica um estiramento que se ajusta a uma distribuição gaussiana (normal), útil para dados que se aproximam dessa distribuição.
  • Gamma Correction: Ajusta o brilho e o contraste de forma não linear, modificando os tons médios da imagem. Útil para realçar detalhes em áreas muito claras ou muito escuras.
  • Brightness/Contrast Adjustment: Controles simples para aumentar/diminuir o brilho geral ou o contraste da imagem exibida.
  • DRA (Dynamic Range Adjustment): Opção que ajusta dinamicamente o estiramento com base apenas nos pixels atualmente visíveis na tela, útil para explorar imagens com grande variação de brilho.

Exemplos Comuns

Melhorar a visibilidade de feições em uma imagem de satélite que parece "lavada" ou com pouco contraste. Realçar detalhes em áreas de sombra ou de brilho intenso em uma fotografia aérea. Ajustar o contraste de um Modelo Digital de Elevação (DEM) para melhor visualização do relevo (antes de aplicar Hillshade). Comparar visualmente diferentes bandas de uma imagem multiespectral ajustando o estiramento de cada uma. Preparar uma imagem para interpretação visual ou digitalização de feições.
