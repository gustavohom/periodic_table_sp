RP

Raster Processing (Clip/Split)

Raster Analysis

Descrição

Ferramentas básicas para extrair ou dividir subconjuntos de um conjunto de dados raster. Permitem focar a análise ou o gerenciamento de dados em áreas geográficas menores ou específicas, similar às operações de extração em dados vetoriais (EX), mas aplicadas a grades de células.

Funções Principais / Ferramentas

  • Clip (Raster): Extrai uma porção retangular ou irregular de um raster de entrada com base em uma extensão definida (coordenadas X,Y mín/máx) ou na forma de uma camada de feições vetoriais (polígono).
    • Clip by Extent: Define a área de corte por coordenadas ou usando a extensão de outra camada.
    • Clip by Polygon Feature: Usa um polígono (ou múltiplos polígonos) de uma camada vetorial como molde. As células fora do(s) polígono(s) são geralmente definidas como NoData no raster de saída. Opção para usar a geometria exata do polígono (pode criar células parciais nas bordas se não alinhadas) ou ajustar à extensão retangular do polígono.
  • Split Raster: Divide um raster grande em múltiplos rasters menores (tiles ou azulejos) com base em critérios como:
    • Tamanho do Tile (Tile Size): Define as dimensões (número de linhas/colunas ou unidades de mapa) de cada tile de saída.
    • Número de Tiles: Divide o raster em um número especificado de tiles.
    • Por Polígonos: Usa uma camada de polígonos de índice (como um Grid Index - GI) para definir a extensão e o nome de cada tile de saída.
  • Extract by Mask: Similar ao Clip por polígono, extrai as células de um raster que caem dentro da área definida por um raster de máscara ou uma camada de feições. Células fora da máscara recebem valor NoData.
  • Extract by Attributes: Cria um novo raster contendo apenas as células do raster de entrada cujos valores atendem a uma consulta SQL (baseada nos valores das células ou em atributos da tabela associada, se houver).
  • Extract by Points: Extrai os valores das células de um ou mais rasters nas localizações exatas definidas por uma camada de pontos. A saída é geralmente uma tabela ou uma camada de pontos com os valores extraídos como atributos.

Exemplos Comuns

Recortar um DEM nacional para a área de um município específico (Clip by Polygon). Extrair dados de imagem de satélite apenas para a área de uma bacia hidrográfica (Extract by Mask). Dividir um grande ortomosaico aéreo em tiles menores para facilitar o gerenciamento e a distribuição (Split Raster). Extrair apenas as células com valor de elevação acima de 1000 metros de um DEM (Extract by Attributes ou Con em Map Algebra). Obter os valores de temperatura de um raster climático para um conjunto de locais de estações meteorológicas (Extract by Points).
