Composite Bands

Remote Sensing

Descrição

Ferramenta que combina múltiplos rasters de banda única (single-band rasters) em um único arquivo raster multiespectral (multi-band raster). É usado principalmente para criar composições coloridas (RGB) a partir de bandas individuais de imagens de satélite ou aéreas, permitindo a visualização em cores reais ou falsas cores.

Funções Principais / Ferramentas

  • Entrada: Uma lista de dois ou mais rasters de banda única. As bandas de entrada devem ter a mesma extensão, resolução (tamanho de célula) e sistema de coordenadas para um resultado correto.
  • Ordem das Bandas: A ordem em que as bandas de entrada são listadas determina a ordem das bandas no raster de saída. Isso é crucial para a exibição correta das composições coloridas.
  • Saída: Um único arquivo raster contendo múltiplas bandas. O formato de saída deve suportar múltiplas bandas (ex: GeoTIFF, IMG, formato de Geodatabase).
  • Aplicação para Visualização RGB: Após criar o raster composto, o usuário pode configurar a exibição no software GIS mapeando quais bandas do arquivo correspondem aos canais Vermelho (Red), Verde (Green) e Azul (Blue) do monitor.
    • Composição Cor Real (True Color): Mapeia as bandas Vermelha, Verde e Azul do sensor para os canais RGB do monitor, respectivamente. Ex: Landsat 8 bandas 4(R), 3(G), 2(B).
    • Composição Falsa Cor (False Color): Mapeia outras bandas para os canais RGB para realçar características específicas. Uma composição comum é mapear Infravermelho Próximo (NIR), Vermelho (Red) e Verde (Green) para os canais R, G, B, respectivamente. Isso faz a vegetação saudável aparecer em tons vibrantes de vermelho. Ex: Landsat 8 bandas 5(NIR), 4(R), 3(G).

Exemplos Comuns

Combinar as bandas individuais Azul, Verde, Vermelho e NIR de uma imagem Landsat ou Sentinel-2 baixadas separadamente em um único arquivo multibanda. Criar um raster composto para poder visualizar a imagem em cores reais ou falsas cores no software GIS. Combinar os resultados de diferentes índices espectrais (ex: NDVI, NDWI, NDBI) como bandas de um único raster para análise visual ou classificação combinada. Agrupar diferentes camadas de dados raster (ex: Elevação, Declividade, Aspecto) em um único arquivo multibanda para facilitar o gerenciamento (embora não seja para visualização RGB direta).
