CM

OD Cost Matrix (Origin-Destination)

Network Analysis

Descrição

Calcula o custo de viagem (impedância - geralmente tempo ou distância) pela rede entre múltiplos pontos de origem e múltiplos pontos de destino. O resultado é uma tabela (matriz) que lista o custo do caminho de menor custo para cada par origem-destino viável.

Funções Principais / Ferramentas

  • Entradas:
    • Origins: Camada de pontos representando os locais de partida.
    • Destinations: Camada de pontos representando os locais de chegada.
    • Network Dataset: A rede usada para calcular os custos.
  • Impedância: Define o custo a ser calculado (ex: Tempo, Distância).
  • Cutoff (Limite - Opcional): Um valor máximo de custo. Pares origem-destino cujo menor custo exceda esse valor não serão incluídos na saída.
  • Número de Destinos a Encontrar (Opcional): Limita o número de destinos mais próximos (em termos de custo) a serem encontrados para cada origem. Se não especificado, calcula para todos os pares possíveis (dentro do cutoff).
  • Restrições e Barreiras: Pode usar as mesmas restrições e barreiras da análise de Rota (RT).
  • Saída: Uma tabela contendo, no mínimo, o ID da Origem, o ID do Destino e o Custo Total calculado para esse par. Pode opcionalmente gerar linhas retas conectando os pares OD, simbolizadas pelo custo.

Exemplos Comuns

Calcular uma tabela de tempos de viagem entre todos os bairros de uma cidade para análise de acessibilidade. Determinar os custos de transporte entre vários centros de distribuição e todas as lojas de varejo que eles atendem. Analisar os tempos de deslocamento de várias áreas residenciais para múltiplos centros de emprego. Gerar dados de entrada (matriz de distâncias/tempos) para modelos de localização-alocação (OS) ou modelos de interação espacial (como o Huff Model - HM). Comparar a acessibilidade a hospitais a partir de diferentes localizações.
