ZS

Zonal Statistics

Raster Analysis

Descrição

Calcula estatísticas descritivas sobre os valores de um raster (raster de valor) para cada zona definida por outro conjunto de dados (raster de zona ou camada de feições vetoriais de zona). Permite resumir as características de uma superfície contínua dentro de áreas ou categorias específicas.

Funções Principais / Ferramentas

  • Entradas:
    • Zone Dataset (Conjunto de Dados de Zona): Define as áreas (zonas) para as quais as estatísticas serão calculadas. Pode ser um raster de inteiros (onde cada valor único representa uma zona) ou uma camada de feições vetoriais (polígonos).
    • Value Raster (Raster de Valor): O raster contendo os valores sobre os quais as estatísticas serão calculadas (ex: DEM, precipitação, densidade populacional).
  • Estatísticas Calculadas (Selecionáveis):
    • Mean (Média), Median (Mediana), Majority (Maioria - valor mais frequente), Minority (Minoria)
    • Minimum (Mínimo), Maximum (Máximo), Range (Amplitude = Max - Min)
    • Standard Deviation (Desvio Padrão), Variety (Número de valores únicos)
    • Sum (Soma), Count (Contagem de células na zona)
    • Percentile (Percentil - requer especificação do percentil)
  • Saída:
    • Zonal Statistics as Table: Cria uma tabela separada onde cada linha corresponde a uma zona e as colunas contêm as estatísticas calculadas para essa zona.
    • Se as zonas forem feições vetoriais: As estatísticas calculadas podem ser anexadas diretamente à tabela de atributos da camada de zonas.
  • Considerar NoData (Opcional): Opção para incluir ou ignorar células NoData do raster de valor nos cálculos estatísticos.

Exemplos Comuns

Calcular a elevação média, mínima e máxima para cada município (zonas = polígonos de municípios, valor = DEM). Determinar a precipitação total acumulada para cada bacia hidrográfica (zonas = polígonos de bacias, valor = raster de precipitação). Calcular a porcentagem de cobertura florestal (valor = raster binário floresta/não floresta, estatística = Média * 100) para cada tipo de solo (zonas = raster de tipos de solo). Encontrar a densidade populacional média dentro de buffers de 1 km ao redor de escolas (zonas = polígonos de buffer, valor = raster de densidade populacional). Determinar o tipo de uso do solo predominante (Majority) em cada setor censitário.
