EX

Extract

Vector Analysis / Conversion

Descrição

Cria um subconjunto de feições a partir de uma camada vetorial maior, utilizando critérios espaciais ou de atributos. É uma operação fundamental para focar a análise em áreas de interesse ou em dados específicos. As ferramentas de extração permitem selecionar, recortar (clip) ou dividir feições para gerar novas camadas com os dados desejados.

Funções Principais / Ferramentas

  • Clip: Extrai feições de entrada que se sobrepõem a uma camada de recorte (como cortar um biscoito com um molde). Mantém os atributos das feições de entrada.
  • Select (Seleção): Cria uma nova camada contendo apenas as feições selecionadas com base em expressões de atributos (SQL) ou localização espacial (relação com outra camada). (Ex: Ferramentas Select Layer By Attribute, Select Layer By Location, seguido de Export Features ou Copy Features).
  • Split (Divisão): Divide uma camada de entrada em múltiplas camadas de saída com base nos polígonos de uma camada de divisão. Cada nova camada corresponde a um polígono da camada de divisão.
  • Table Select: Cria uma nova tabela contendo apenas os registros selecionados de uma tabela de atributos com base em uma consulta SQL.

Exemplos Comuns

Recortar todas as estradas que estão dentro do limite de um município específico (Clip). Selecionar apenas os rios com vazão acima de um certo valor ou que cruzam uma área de preservação (Select Layer By Attribute / Select Layer By Location). Dividir uma camada de dados de vegetação nacional em camadas separadas por estado (Split). Extrair apenas os registros de clientes de uma determinada cidade de uma tabela geral (Table Select).
