Contours / Isolines

Raster Analysis

Descrição

Gera linhas (isolines) que conectam pontos de igual valor em uma superfície raster contínua. Quando a superfície representa elevação (DEM), as linhas são chamadas de curvas de nível (contours). O mesmo princípio pode ser aplicado a outras superfícies, como temperatura (isotermas), pressão (isóbaras) ou concentração de poluentes (isopletas).

Funções Principais / Ferramentas

  • Entrada: Um raster representando uma superfície contínua (ex: DEM, temperatura interpolada).
  • Intervalo de Contorno (Contour Interval): A diferença de valor entre linhas de contorno adjacentes (ex: curvas de nível a cada 10 metros).
  • Contorno Base (Base Contour): Um valor opcional a partir do qual os contornos serão gerados (ex: começar do nível do mar, valor 0).
  • Fator Z (Z Factor): Fator de conversão se as unidades verticais (Z) do raster forem diferentes das unidades horizontais (X, Y).
  • Tipo de Saída: Geralmente uma camada de polilinhas vetoriais, onde cada linha possui um atributo com o valor de contorno correspondente. Pode haver opções para gerar contornos preenchidos (polígonos).
  • Suavização (Smoothing - Opcional): Opções para suavizar a aparência das linhas de contorno geradas.
  • Contornos Índice (Index Contours - Opcional): Permite especificar um intervalo maior para gerar contornos mais espessos ou destacados (ex: curvas mestras a cada 50 metros).

Exemplos Comuns

Gerar curvas de nível a cada 20 metros a partir de um Modelo Digital de Elevação (DEM) para representação topográfica. Criar linhas de isóbaras (igual pressão atmosférica) a partir de um raster de dados meteorológicos. Gerar isopletas mostrando áreas com igual concentração de ruído ao redor de um aeroporto. Criar curvas de isodeclividade (linhas de igual declividade) a partir de um raster de declividade. Visualizar a distribuição de temperatura em uma região gerando isotermas a partir de dados interpolados.
