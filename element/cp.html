Cost Path / Least Cost Path

Raster Analysis

Descrição

Calcula o caminho de menor custo acumulado entre um destino (ou múltiplos destinos) e uma origem (ou múltiplas origens) sobre uma superfície de custo. A superfície de custo é um raster onde cada célula representa o custo (ex: tempo, dinheiro, dificuldade, risco) para atravessá-la. A ferramenta utiliza resultados de análises prévias de distância de custo (Cost Distance, Cost Back Link).

Funções Principais / Ferramentas / Workflow Típico

  • 1. Criação da Superfície de Custo (Cost Surface): Um raster onde cada célula tem um valor representando o custo para mover-se através dela. Células com custo mais alto são mais "difíceis" ou "caras" de atravessar. Pode ser derivado de tipo de solo, declividade, uso do solo, etc.
  • 2. Cálculo da Distância de Custo (Cost Distance / Cost Allocation): Calcula, para cada célula, o menor custo acumulado para alcançar a origem mais próxima (ou uma origem específica) atravessando a superfície de custo. O resultado é um raster de custo acumulado.
  • 3. Cálculo do Back Link (Cost Back Link / Cost Direction): Cria um raster onde cada célula aponta para a célula vizinha que está no caminho de menor custo acumulado de volta para a origem mais próxima. Define a direção do caminho ótimo a partir de qualquer célula.
  • 4. Cost Path (Caminho de Menor Custo): Utiliza o raster de custo acumulado e o raster de back link para traçar o caminho específico de menor custo entre um ponto de destino e sua origem de menor custo. A saída é geralmente uma camada vetorial de linha.
  • Opções (Cost Path):
    • Input Destination: Ponto(s) ou raster de destino.
    • Input Cost Distance Raster: Saída da ferramenta Cost Distance.
    • Input Cost Backlink Raster: Saída da ferramenta Cost Back Link.
    • Path Type: Define como lidar com múltiplos destinos (ex: EACH_CELL encontra o caminho de cada célula de destino, BEST_SINGLE encontra o caminho para o destino de menor custo global).

Exemplos Comuns

Encontrar a rota de menor custo para construir uma nova estrada ou linha de transmissão, minimizando custos de construção relacionados à declividade e tipo de terreno. Modelar o caminho mais provável que um animal selvagem usaria para se mover entre duas áreas de habitat, considerando barreiras e corredores. Planejar a rota de uma trilha de caminhada que minimize o ganho de elevação acumulado. Determinar o caminho mais rápido para equipes de resgate alcançarem um local remoto, considerando a dificuldade de deslocamento em diferentes tipos de vegetação. Modelar a dispersão de populações ou doenças considerando fatores de resistência ambiental.
