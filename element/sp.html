SP

Sampling

Data Management (Vector)

Descrição

Cria um conjunto de pontos ou seleciona um subconjunto de feições existentes (pontos, linhas ou polígonos) com base em um método de amostragem específico. A amostragem espacial é usada para coletar dados representativos em campo, reduzir o tamanho de grandes conjuntos de dados para análise exploratória ou modelagem, ou para gerar locais para validação de modelos.

Funções Principais / Ferramentas / Métodos

  • Create Random Points: Gera um número especificado de pontos em locais aleatórios dentro de uma extensão definida (retângulo, polígono de estudo) ou dentro de feições de uma camada de entrada.
  • Create Fishnet / Regular Points: Cria uma grade regular de pontos com espaçamento definido pelo usuário sobre uma área de interesse.
  • Stratified Random Sampling: Divide a área de estudo ou a população de feições em estratos (subgrupos, ex: tipos de solo, zonas de risco) e, em seguida, gera um número proporcional ou fixo de amostras aleatórias dentro de cada estrato. Garante representatividade de todos os subgrupos.
  • Systematic Sampling: Seleciona feições ou gera pontos em intervalos regulares (ex: a cada 100 metros ao longo de uma linha, selecionar 1 a cada 10 polígonos ordenados por área).
  • Cluster Sampling: Seleciona aleatoriamente grupos (clusters) de feições e amostra todas ou algumas feições dentro dos clusters selecionados.
  • Subset Features (Seleção Aleatória): Seleciona aleatoriamente uma porcentagem ou um número fixo de feições de uma camada existente.

Exemplos Comuns

Gerar 100 locais aleatórios dentro de um parque nacional para realizar inventário de espécies (Create Random Points). Criar uma grade de pontos a cada 500 metros sobre uma área agrícola para coleta de amostras de solo (Create Fishnet / Regular Points). Selecionar locais para validação de um mapa de uso do solo, garantindo que todas as classes de uso do solo sejam amostradas proporcionalmente à sua área (Stratified Random Sampling). Selecionar 10% das parcelas de uma cidade aleatoriamente para uma pesquisa detalhada (Subset Features). Gerar pontos de monitoramento a cada 1 km ao longo de um rio (Systematic Sampling ao longo de linha).
