CON

Conditional Tool (Con)

Raster Analysis

Descrição

Ferramenta de Álgebra de Mapas (MA) que realiza uma avaliação condicional (if/then/else) para cada célula de um raster de entrada. Se a condição especificada para uma célula for verdadeira, ela recebe um valor; se for falsa, recebe outro valor. Permite criar rasters de saída com base em critérios lógicos aplicados aos valores das células.

Funções Principais / Sintaxe Típica

  • Estrutura Lógica: `Con(condition_raster, true_raster_or_value, {false_raster_or_value})`
  • Condition Raster (Raster de Condição): Um raster (ou uma expressão que resulta em um raster) avaliado logicamente. Geralmente é um raster booleano (0 e 1) resultante de uma operação relacional (>, <, ==, etc.) ou lógica (AND, OR, etc.), ou qualquer raster onde 0 é interpretado como FALSO e qualquer outro valor como VERDADEIRO.
  • True Raster or Value (Valor se Verdadeiro): O valor que será atribuído à célula de saída se a condição for verdadeira na célula correspondente. Pode ser um valor constante, o valor de outro raster na mesma célula, ou uma expressão.
  • False Raster or Value (Valor se Falso - Opcional): O valor que será atribuído à célula de saída se a condição for falsa. Se omitido, as células onde a condição é falsa geralmente recebem NoData. Pode ser um valor constante, o valor de outro raster ou uma expressão.
  • Aninhamento: Instruções `Con` podem ser aninhadas para criar lógicas mais complexas (if/then/elseif/else). `Con(cond1, val1, Con(cond2, val2, val3))`

Exemplos Comuns

Criar um raster binário mostrando áreas com elevação acima de 1000 metros: `Con("DEM" > 1000, 1, 0)`. Atribuir um custo de travessia alto (100) para áreas com declividade > 20% e baixo (10) para as demais: `Con("Slope_Percent" > 20, 100, 10)`. Substituir valores NoData em um raster 'Dados' pelos valores correspondentes de um raster 'Base': `Con(IsNull("Dados"), "Base", "Dados")`. Classificar áreas como 'Adequado' (valor 1) se forem Floresta E tiverem declividade baixa, caso contrário 'Inadequado' (valor 0): `Con(("UsoSolo" == 5) & ("Declividade" < 10), 1, 0)`. Atribuir um valor de risco (1, 2 ou 3) com base em intervalos de distância de rios: `Con("Dist_Rio" < 100, 3, Con("Dist_Rio" < 500, 2, 1))`.

Nota: A ferramenta `Con` é uma das mais versáteis e fundamentais na Álgebra de Mapas para implementar lógica condicional em análises raster.
