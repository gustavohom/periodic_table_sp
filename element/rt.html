RT

Route Analysis

Network Analysis

Descrição

Calcula a rota ótima (geralmente a mais rápida ou a mais curta) entre duas ou mais localizações (paradas ou "stops") utilizando um Network Dataset (conjunto de dados de rede, como ruas, ferrovias, etc.). Permite encontrar o melhor caminho para viagens, entregas, inspeções, considerando as características da rede.

Funções Principais / Ferramentas

  • Entradas:
    • Network Dataset: A rede sobre a qual a rota será calculada (ex: ruas com limites de velocidade, restrições de sentido).
    • Stops (Paradas): Dois ou more pontos que definem o início, o fim e possíveis paradas intermediárias da rota.
  • Impedância (Custo): Define o que está sendo minimizado (ex: Tempo de Viagem, Distância). O Network Dataset geralmente armazena esses custos para cada segmento da rede.
  • Restrições: Permite incorporar regras como evitar pedágios, não usar vias específicas, respeitar sentidos únicos, proibições de conversão, restrições de altura/peso.
  • Barreiras: Permite adicionar pontos, linhas ou polígonos temporários que bloqueiam ou adicionam custo à passagem pela rede (ex: acidente, área de construção).
  • Otimização da Ordem das Paradas: Se houver múltiplas paradas intermediárias, a ferramenta pode encontrar a sequência ótima para visitá-las, minimizando o custo total da rota (problema do caixeiro viajante - TSP).
  • Saída: Uma camada de linha representando a rota ótima, geralmente com atributos como tempo e distância totais. Pode também gerar instruções de direção (ver DR).

Exemplos Comuns

Calcular a rota mais rápida de casa para o trabalho em um determinado horário (considerando tráfego, se disponível na rede). Planejar a rota de entrega para um motorista que precisa visitar 10 clientes, encontrando a sequência e o caminho mais eficientes. Determinar o caminho mais curto para uma ambulância chegar a um local de emergência. Encontrar a rota para um caminhão pesado que evite pontes com limite de peso baixo. Simular o tempo de viagem entre diferentes bairros usando a rede de transporte público.
