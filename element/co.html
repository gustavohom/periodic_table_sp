COGO (Coordinate Geometry)

Data Management (Vector)

Descrição

Conjunto de ferramentas de edição e construção geométrica baseadas em princípios de levantamento topográfico. COGO (Coordinate Geometry) permite criar e modificar feições lineares e pontuais inserindo diretamente medições como rumos (bearings), azimutes, distâncias e ângulos, em vez de apenas clicar no mapa. É fundamental para inserir dados de levantamentos de campo, plantas de loteamento e descrições legais de propriedades com precisão.

Funções Principais / Ferramentas

  • Travessia (Traverse Tool): Ferramenta principal para criar uma sequência de linhas e pontos inserindo pares de direção (rumo, azimute, ângulo de deflexão) e distância para cada segmento. Permite ajustes para fechamento de poligonais.
  • Entrada de Dados COGO: Campos e interfaces para digitar medições nos formatos comuns de levantamento (ex: Graus Minutos Segundos para ângulos, unidades métricas/imperiais para distâncias).
  • Construção por Ângulo e Distância: Criar linhas a partir de um ponto conhecido especificando um ângulo e uma distância.
  • Construção de Curvas: Ferramentas para criar arcos circulares especificando parâmetros como raio, comprimento do arco, ângulo central, tangente, corda.
  • Interseções: Calcular pontos de interseção entre linhas definidas por direções ou entre círculos.
  • Relatório COGO: Gerar relatórios listando as dimensões COGO (direção, distância, raio, etc.) das feições selecionadas.
  • Atributos COGO (Opcional): Habilidade de armazenar as dimensões COGO inseridas como atributos das feições lineares criadas (frequentemente usado em conjunto com o Parcel Fabric - PF).

Exemplos Comuns

Digitalizar os limites de um lote a partir da descrição legal que contém rumos e distâncias. Inserir os dados de uma poligonal de levantamento topográfico para criar os pontos e linhas no GIS. Construir o eixo de uma estrada com curvas circulares a partir dos dados do projeto de engenharia. Reconstruir um limite de propriedade antigo a partir de um croqui com medições. Criar linhas de servidão com base em descrições de ângulo e distância a partir de um ponto de controle.
