Grid Index / Map Series

Editing / Cartography

Descrição

Cria uma camada de polígonos regulares (geralmente retangulares ou hexagonais) ou uma série de polígonos sequenciais que cobrem uma área de interesse ou seguem uma feição linear. Essa camada de índice é usada principalmente para definir as extensões de múltiplas páginas em um atlas ou série de mapas (Map Series / Data Driven Pages), garantindo uma cobertura sistemática e organizada da área.

Funções Principais / Ferramentas

  • Grid Index Features / Create Fishnet: Gera uma rede (malha) de células retangulares (ou poligonais) de tamanho e espaçamento definidos pelo usuário sobre uma determinada extensão.
  • Tessellation (Hexagonal/Quadrado): Cria uma cobertura completa da área com polígonos regulares que se encaixam perfeitamente (ex: hexágonos, quadrados, triângulos).
  • Strip Map Index Features: Cria uma série de polígonos retangulares sequenciais que seguem o curso de uma feição linear (ex: estrada, rio, pipeline), ideal para mapas de rota ou projetos lineares longos.
  • Integração com Map Series / Data Driven Pages / QGIS Atlas: A camada de índice gerada é usada para controlar a extensão geográfica de cada página em uma série de mapas automatizada. Campos na tabela de atributos do índice (como número da página, nome da folha) podem ser usados para rotular e organizar as páginas.
  • Geração de Rótulos e Escalas: Pode calcular automaticamente rótulos de página, escalas apropriadas e informações de folhas adjacentes para incluir no layout do mapa.

Exemplos Comuns

Criar um conjunto de folhas de mapa em escala 1:10.000 para cobrir um município inteiro. Gerar um atlas mostrando detalhes de cada distrito censitário da cidade. Produzir um mapa sequencial de um projeto de construção de rodovia, com cada página mostrando um trecho de 5 km. Criar uma grade hexagonal sobre uma área de estudo para análise de densidade ou amostragem sistemática, e usar essa grade para gerar mapas individuais de cada célula.
