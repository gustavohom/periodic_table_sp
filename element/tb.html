Table Tools / Management

Tables

Descrição

Conjunto de ferramentas e funcionalidades para criar, gerenciar e manipular tabelas de atributos associadas a camadas geográficas ou tabelas independentes dentro de um ambiente GIS. A gestão eficaz das tabelas é fundamental, pois elas armazenam as informações descritivas (não espaciais) das feições.

Funções Principais / Ferramentas

  • Gerenciamento de Campos (Fields):
    • Add Field: Adiciona uma nova coluna (campo) à tabela, especificando nome, tipo de dado (texto, número inteiro/decimal, data), precisão, escala, etc.
    • Delete Field: Remove uma coluna existente da tabela.
    • Calculate Field: Preenche ou atualiza os valores de um campo usando expressões matemáticas, lógicas, de texto ou funções (Python, Arcade, SQL).
    • Reorder/Rename/Hide Fields: Altera a ordem de exibição, renomeia ou oculta campos na visualização da tabela.
    • Alter Field Properties: Modifica propriedades de campos existentes (nome, alias, tipo - se permitido).
  • Domínios (Domains): Cria regras para restringir os valores permitidos em um campo, garantindo a consistência dos dados. Podem ser de Valor Codificado (lista de valores permitidos com descrições) ou de Intervalo (Range - valor mínimo e máximo).
  • Subtipos (Subtypes): Permite categorizar feições dentro de uma mesma camada, definindo valores padrão e domínios diferentes para cada subtipo (ex: uma camada 'Estradas' com subtipos 'Rodovia', 'Municipal', 'Não Pavimentada').
  • Indexação (Attribute Index): Cria índices em campos frequentemente usados em consultas ou joins para acelerar o desempenho dessas operações.
  • Visualização e Seleção: Ferramentas para ordenar, filtrar e selecionar registros na tabela.

Exemplos Comuns

Adicionar um campo 'Data_Coleta' a uma camada de pontos de amostra. Calcular a densidade populacional em um campo 'Dens_Pop' a partir dos campos 'Populacao' e 'Area_km2'. Criar um domínio de valores codificados para o campo 'Condicao' de uma camada de hidrantes ('Bom', 'Regular', 'Ruim'). Definir subtipos para uma camada de dutos ('Gás', 'Óleo', 'Água') com diâmetros padrão diferentes para cada um. Criar um índice no campo 'ID_Lote' para acelerar joins com tabelas de proprietários. Selecionar todos os registros onde o campo 'Status' é igual a 'Ativo'.
