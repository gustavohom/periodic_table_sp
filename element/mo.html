Mosaic (Raster)

Raster Data Management

Descrição

Combina duas ou more imagens raster adjacentes ou sobrepostas em uma única imagem raster contínua (mosaico). O processo pode envolver o gerenciamento de áreas de sobreposição, ajuste de cores/radiometria e a criação de uma imagem de saída sem costuras visíveis.

Funções Principais / Ferramentas

  • Mosaic Tool / Create Mosaic Dataset: Ferramentas que permitem selecionar múltiplas imagens raster de entrada e definir como elas serão combinadas.
    • Mosaic Tool (tradicional): Cria um novo arquivo raster físico contendo o mosaico.
    • Mosaic Dataset (ex: ArcGIS): Cria um contêiner virtual que gerencia uma coleção de rasters como se fossem um único mosaico, sem necessariamente criar um novo arquivo gigante. Permite processamento on-the-fly, definição de regras de mosaico complexas e atualizações fáceis.
  • Métodos de Mosaico (Mosaic Method / Operator): Define como os valores dos pixels nas áreas de sobreposição são tratados:
    • First/Last: Usa o valor do primeiro/último raster na ordem de entrada.
    • Blend: Suaviza a transição entre os rasters na área de sobreposição (ex: média ponderada pela distância à borda).
    • Minimum/Maximum/Mean: Usa o valor mínimo/máximo/médio dos pixels sobrepostos.
    • By Attribute: Usa um campo de atributo (ex: data de aquisição, % de nuvens) para escolher qual raster tem prioridade na sobreposição. (Mais comum em Mosaic Datasets).
  • Color Balancing / Correction: Ferramentas para ajustar as diferenças de cor e brilho entre as imagens de entrada para criar uma aparência visualmente homogênea no mosaico final.
  • Seamline Generation: Criação automática ou manual de linhas de costura (seamlines) nas áreas de sobreposição, definindo o local exato da transição entre as imagens para minimizar diferenças visuais (ex: seguir estradas ou rios). (Mais comum em Mosaic Datasets).
  • Footprints e Boundary: Gerenciamento dos contornos exatos de cada imagem dentro do mosaico.

Exemplos Comuns

Criar uma única imagem de ortofoto cobrindo um município inteiro a partir de múltiplas fotos aéreas adjacentes. Combinar várias cenas de imagem de satélite para cobrir uma grande região de estudo. Montar um mosaico de folhas de mapa topográfico escaneadas e georreferenciadas. Criar um Modelo Digital de Elevação (DEM) contínuo a partir de vários tiles DEM separados. Gerenciar uma coleção de imagens históricas de uma área em um Mosaic Dataset, permitindo visualizá-las individualmente ou como um mosaico baseado na data.
