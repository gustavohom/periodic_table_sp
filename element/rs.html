Resample (Raster)

Raster Data Management

Descrição

Altera a resolução espacial (tamanho da célula ou pixel) de um conjunto de dados raster. O processo calcula novos valores de célula para a grade de saída com base nos valores das células do raster de entrada original, utilizando diferentes técnicas de interpolação para determinar esses novos valores. É necessário quando se deseja combinar ou analisar rasters com diferentes resoluções.

Funções Principais / Técnicas de Reamostragem

  • Definição da Resolução de Saída: O usuário especifica o novo tamanho da célula desejado para o raster de saída. Pode ser maior (downsampling/agregacão) ou menor (upsampling/detalhamento) que a resolução original.
  • Técnicas de Interpolação (Resampling Techniques): Determinam como o valor de cada nova célula de saída é calculado a partir das células de entrada vizinhas:
    • Nearest Neighbor (Vizinho Mais Próximo): Atribui à célula de saída o valor da célula de entrada mais próxima do seu centro. É rápido e preserva os valores originais dos dados, sendo ideal para dados categóricos (ex: uso do solo), mas pode resultar em uma aparência "quadriculada".
    • Bilinear Interpolation (Interpolação Bilinear): Calcula o valor da célula de saída como uma média ponderada pela distância dos 4 centros de célula de entrada mais próximos. Produz uma aparência mais suave, adequada para dados contínuos (ex: elevação, temperatura), mas altera os valores originais.
    • Cubic Convolution (Convolução Cúbica): Calcula o valor da célula de saída a partir de uma vizinhança maior (16 centros de célula mais próximos) usando uma função cúbica. É mais complexo computacionalmente, produz resultados ainda mais suaves que o bilinear, sendo também adequado para dados contínuos, mas pode gerar valores fora do intervalo original.
    • Majority (Maioria): Similar ao Nearest Neighbor, mas usa o valor mais frequente na vizinhança. Adequado para dados categóricos ao fazer downsampling.
    • Outras (ex: Average, Min, Max, Median): Podem estar disponíveis para agregação ao fazer downsampling.
  • Alinhamento de Células (Snap Raster): Opção para garantir que as células do raster de saída se alinhem perfeitamente com as células de outro raster de referência.

Exemplos Comuns

Reduzir a resolução de um DEM de 10m para 30m para compatibilizá-lo com imagens Landsat (downsampling, talvez usando Average ou Bilinear). Aumentar a resolução de um raster de precipitação de baixa resolução para fins de visualização (upsampling, usando Bilinear ou Cubic, ciente da interpolação). Garantir que uma camada de uso do solo (categórica) tenha a mesma resolução de 30m que outras camadas em um modelo, usando Nearest Neighbor para preservar as classes. Reamostrar todas as camadas de entrada de um modelo de adequabilidade para uma resolução comum antes de combiná-las.
