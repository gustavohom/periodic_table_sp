XY

Add XY Coordinates / Create Points from Table

Tables

Descrição

Cria uma camada de pontos georreferenciados a partir de uma tabela que contém colunas com coordenadas X (longitude, Leste) e Y (latitude, Norte). Esta é uma forma comum de importar dados coletados em campo (GPS), dados de planilhas ou bancos de dados externos que possuem informações de localização explícitas.

Funções Principais / Ferramentas

  • Identificação dos Campos XY: O usuário especifica quais colunas na tabela contêm as coordenadas X e Y.
  • Definição do Sistema de Coordenadas (CRS): É crucial especificar o Sistema de Referência de Coordenadas (SRC / CRS) em que as coordenadas da tabela estão (ex: WGS84 Lat/Long, UTM Zona 23S). Se não for definido corretamente, os pontos aparecerão no lugar errado.
  • Campo Z Opcional: Permite especificar uma coluna com valores de elevação (Z) para criar pontos 3D.
  • Criação da Camada:
    • Make XY Event Layer (ou similar): Cria uma camada temporária em memória a partir da tabela. Útil para visualização rápida, mas precisa ser salva permanentemente (exportada).
    • XY Table To Point (ou similar): Cria diretamente uma nova camada de pontos (feature class) persistente no disco ou geodatabase.
  • Manutenção do Link (Opcional): Algumas ferramentas podem manter um link dinâmico com a tabela original, atualizando a camada de pontos se a tabela mudar (mais comum com Event Layers).

Exemplos Comuns

Mapear a localização de clientes a partir de uma planilha do Excel com colunas 'Latitude' e 'Longitude'. Criar uma camada de pontos de ocorrências de espécies a partir de dados de GPS coletados em campo e armazenados em um arquivo CSV. Visualizar a localização de poços de petróleo listados em um banco de dados com coordenadas UTM. Transformar uma tabela de endereços geocodificados (que já possuem X e Y) em uma camada de pontos espacialmente habilitada.
