WS

Web Services (Publish/Consume)

Data Management (Vector)

Descrição

Refere-se à capacidade de publicar camadas de dados geoespaciais (vetoriais ou raster) de um servidor GIS para serem acessadas através da internet por outros softwares GIS (desktop, web, móvel) ou aplicações, utilizando protocolos padronizados. Também envolve a capacidade de consumir (importar/conectar) dados de serviços web oferecidos por terceiros.

Funções Principais / Tipos de Serviço

  • Publicação de Serviços (Server-Side): Usando software de servidor GIS (ex: ArcGIS Server, GeoServer, QGIS Server), o usuário configura e publica camadas como serviços web. Tipos comuns incluem:
    • Map Service (Serviço de Mapa - ex: WMS, ArcGIS Map Service): Fornece imagens de mapa pré-renderizadas (tiles ou dinâmicas). O cliente recebe uma imagem, não os dados brutos.
    • Feature Service (Serviço de Feição - ex: WFS, ArcGIS Feature Service): Permite aos clientes acessar a geometria e os atributos das feições vetoriais. Possibilita consulta, visualização e, frequentemente, edição dos dados pelo cliente.
    • Tile Service (Serviço de Tile/Cache - ex: WMTS, ArcGIS Tiled Map Service): Fornece tiles de mapa pré-renderizados e armazenados em cache para performance rápida, ideal para mapas base.
    • Geoprocessing Service (Serviço de Geoprocessamento): Publica uma ferramenta ou modelo de análise GIS como um serviço que pode ser executado remotamente por clientes.
    • Image Service (Serviço de Imagem): Fornece acesso a dados raster, permitindo visualização, consulta de valores de pixel e processamento on-the-fly.
  • Consumo de Serviços (Client-Side): Softwares GIS desktop (ArcGIS Pro, QGIS) e plataformas de mapeamento web (ArcGIS Online, Mapbox, Leaflet, OpenLayers) podem se conectar a esses serviços para exibir e interagir com os dados.
  • Protocolos Padrão OGC (Open Geospatial Consortium): WMS (Web Map Service), WFS (Web Feature Service), WMTS (Web Map Tile Service), WCS (Web Coverage Service - para raster) garantem interoperabilidade entre diferentes softwares.
  • Formatos Relacionados: GeoRSS (feeds RSS com localização), KML (usado pelo Google Earth, pode ser servido via web).

Exemplos Comuns

Publicar uma camada de limites municipais como um WFS para que outras agências possam consumi-la em seus próprios sistemas GIS. Conectar-se a um WMS de imagens de satélite fornecido por uma agência espacial para usar como mapa base. Consumir um Feature Service de dados de tráfego em tempo real em um painel de controle operacional. Publicar um modelo de cálculo de área de serviço como um Geoprocessing Service para ser usado por uma aplicação web pública. Disponibilizar um cache de tiles de um mapa base personalizado para uso em aplicações móveis.
