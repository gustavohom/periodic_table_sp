# Periodic Table for Spatial Analysis

Repositório com uma recriação interativa da Tabela Periódica para Análise Espacial, inspirada na versão da ESRI Maps We Love. Este projeto utiliza HTML e CSS para visualizar diferentes conceitos e ferramentas de Geoprocessamento/Análise Espacial em um formato familiar de tabela periódica.

## 📖 Descrição

Este projeto visa ser uma ferramenta visual e educacional para explorar a vasta gama de técnicas disponíveis em Análise Espacial. Cada "elemento" na tabela representa uma ferramenta, conceito ou domínio de aplicação em GIS, agrupados por categorias e codificados por cores para fácil identificação. Ao clicar em um elemento, o usuário é direcionado para uma página de detalhes (para os elementos já implementados) que explica o conceito com mais profundidade.

## ✨ Funcionalidades

*   **Layout Interativo:** Tabela organizada usando CSS Grid, mimetizando a estrutura da tabela periódica.
*   **Categorização Visual:** Elementos agrupados e coloridos por categorias (Análise Vetorial, Análise Raster, Gerenciamento de Dados, Sensoriamento Remoto, etc.).
*   **Hover Effects:** Feedback visual ao passar o mouse sobre os elementos.
*   **Páginas de Detalhe:** Links para páginas individuais que explicam cada ferramenta/conceito (implementado para um subconjunto dos elementos).
    *   Descrição detalhada ou resumida.
    *   Funções principais / Conceitos chave.
    *   Exemplos de aplicação comuns.
*   **Navegação nas Páginas de Detalhe:** Botões "Anterior", "Próximo" e "Voltar para Tabela" para facilitar a exploração.
*   **Design Responsivo (Básico):** O container da tabela permite rolagem horizontal em telas menores.
